# `Point`

Package: `org.firstinspires.ftc.teamcode.adaptive`

Mutable 2D field coordinate for geofence APIs. Pedro 2.x has `Pose`, not `Point`; this type exists so `FoulPreventionBox` can reuse XY without allocating in `loop()`.

```java
public Point()
public Point(double x, double y)
public Point set(double x, double y)
public Point set(Point other)
public double getX()
public double getY()
public void setX(double x)
public void setY(double y)
```

Prefer `set(x, y)` on a field allocated in `init` instead of `new Point(...)` inside `loop()`.
