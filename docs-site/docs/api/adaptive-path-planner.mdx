# `AdaptivePathPlanner`

Package: `org.firstinspires.ftc.teamcode.adaptive`

| Name | Value |
| --- | --- |
| `DEFAULT_COOLDOWN_MS` | `300` |
| `DEFAULT_CONTROL_POINT_FRACTION` | `0.35` |
| `DEFAULT_MIN_REPLAN_DISTANCE_INCHES` | `1.0` |
| `DEFAULT_VELOCITY_TANGENT_EPS` | `0.5` in/s |

## Constructors

```java
public AdaptivePathPlanner(Follower follower, ImpactDetector impactDetector)
public AdaptivePathPlanner(Follower follower, ImpactDetector impactDetector,
                           long cooldownMs)
```

`follower` and `impactDetector` must be non-null.

## Loop and injection

```java
public boolean update()
public boolean forceReplan()
```

`update()` returns `true` only when a new `Path` was given to `follower.followPath`. `forceReplan()` does not touch the detector.

## Target and geofence

```java
public void setTargetPose(Pose targetPose)
public void setTargetPose(double x, double y, double heading)
public Pose getTargetPose()
public void setFoulPreventionBox(FoulPreventionBox foulPrevention)
public FoulPreventionBox getFoulPreventionBox()
```

`setTargetPose(null)` disables injection; latches are still consumed in `update()`.
