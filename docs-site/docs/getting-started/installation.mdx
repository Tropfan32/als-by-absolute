# Installation

## Clone the robot project

```bash
git clone https://github.com/aqqusr/aacs.git
```

Open the **repository root** in Android Studio (Gradle import). Sync, then deploy **FtcRobotController** + **TeamCode** to the Robot Controller.

Team code that matters:

```text
TeamCode/src/main/java/org/firstinspires/ftc/teamcode/
  adaptive/          # AACS modules + AdaptiveTestOpMode
  pedroPathing/      # Constants.java (Pinpoint + FollowerBuilder)
```

Pinpoint is already wired in `Constants.createFollower()`:

```java
return new FollowerBuilder(followerConstants, hardwareMap)
        .pinpointLocalizer(localizerConstants)
        .pathConstraints(pathConstraints)
        .build();
```

## Verify on the field

1. Keep the robot **still** through OpMode `init` (Pinpoint IMU).
2. Driver Station → TeleOp → **Adaptive Pipeline Test** (group `Adaptive`).
3. Press PLAY, then **A** to drive to Target Alpha.

Gamepad map is documented in [OpMode integration](../setup/opmode-integration.mdx).

## Documentation site (optional)

This folder (`docs-site/`) is a Docusaurus 3 app. From the repo root:

```bash
cd docs-site
npm install
npm start
```

The production site is intended for GitHub Pages at:

`https://aqqusr.github.io/aacs/`

Pushes to `master` that touch docs or this workflow build and publish via [`.github/workflows/deploy-docs.yml`](https://github.com/aqqusr/aacs/blob/master/.github/workflows/deploy-docs.yml). Enable **Pages** on the repo: source **GitHub Actions** or the `gh-pages` branch, matching the workflow you use.
