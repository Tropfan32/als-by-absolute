# Prerequisites

## Software

- [Android Studio Ladybug (2024.2)](https://developer.android.com/studio) or newer
- JDK bundled with Android Studio
- Node.js **20+** (only if you build this documentation site locally)
- Git

## Robot hardware

- FTC Control Hub + Driver Station
- Drivetrain Pedro can follow (mecanum is the usual quickstart case)
- goBILDA **Pinpoint** on I2C, hardware map name `pinpoint`
- Two odometry pods (quickstart assumes **goBILDA 4-bar**)

## Knowledge

You should already be able to:

1. Deploy TeamCode to the Hub
2. Run Pedro’s **Tuning** OpMode and get a follower that holds a line
3. Read field poses in **Pedro inches** — origin at a corner, axes roughly `[0, 144]`

Official references:

- [FTC docs](https://ftc-docs.firstinspires.org/index.html)
- [Pedro Pathing](https://pedropathing.com)
- [Pinpoint localization](https://pedropathing.com/docs/pathing/tuning/localization/pinpoint)

:::warning Illegal zones change every season
`AdaptiveTestOpMode` ships **sample** AABBs (opponent wing + a center “submersible”). Replace them with the current game’s Alliance / opponent restrictions before a qualifying match.
:::
