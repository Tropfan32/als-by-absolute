# FoulPreventionBox

Geofence for recovery Béziers: **field rectangle** plus illegal **AABB** / **polygon** zones (Alliance partner, opponent wing, etc.).

Register zones in `init()`, never in `loop()`. Queries use primitives and preallocated buffers.

## What “illegal” means

`intersectsRestrictedZone(p1, p2)` is true if the segment:

- Leaves the field box (default Pedro `[0, 144]` inches), or
- Hits any registered AABB (Liang–Barsky) or polygon (point-in-poly + edge tests)

## Control point projection

`getAdjustedControlPoint(start, target, proposed)`:

1. Clamp proposed `P1` to the field inset (`clearanceInches`).
2. If `P1` is inside a zone, push it out the **nearest AABB face** (plus clearance), or radially for polygons.
3. If `start→P1` or `P1→target` still clips, offset `P1` **perpendicular** to the start–target chord and pick the first legal candidate.

The returned `Point` is **reused**. Copy `x,y` immediately (the planner does this into a new `Pose`).

## Planner integration

`AdaptivePathPlanner.setFoulPreventionBox(box)` runs `P1` through that projection, then samples the quadratic (10 segments). If the sample still clips, the replan is **aborted** — better to keep the old path than foul.

:::warning
A single quadratic cannot thread every obstacle. If start and goal sit on opposite sides of a wide illegal box, AACS skips rather than inventing a multi-waypoint detour. Add waypoints in your Auto script for those geometries.
:::
